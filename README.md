# Yoga To You — clickable demo

This is a **clickable HTML demo** of a Yoga To You site concept. It is **not** the live Yoga To You website.

- Desktop-first layout (1280px). On a phone the full desktop mock scales down instead of reflowing.
- Forms do not send anything.
- Public demo repo for review on a phone or laptop.

Not affiliated as the production site at yogatoyoupdx.com.
